# Academic writing and external validation standard

## Writing

- Use concise academic language.
- State the population, reference year, unit, and method for every principal result.
- Separate observed values, model estimates, legal interpretations, and scenarios.
- Avoid promotional language and unsupported causal claims.
- Report material limitations once, adjacent to the affected result.
- Use tables for comparisons and short declarative titles for figures and slides.

## External validation

Project estimates must be compared, where definitions permit, with:

1. Observatorio do Codigo Florestal (OCF), including the Forest Code
   Thermometer and state diagnostics.
2. Brazilian Forest Service (SFB) and SICAR public regularization indicators.
3. Mato Grosso SEMA/SIMCAR administrative statistics.
4. MapBiomas land-cover and native-vegetation estimates.
5. INPE/PRODES deforestation data when temporal clearing is evaluated.

Comparisons must report differences in population, spatial coverage, reference
date, validation status, legal assumptions, and treatment of overlapping CAR
records. External estimates are benchmarks, not automatically ground truth.
