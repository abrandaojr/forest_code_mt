# Project structure

| Folder | Purpose |
|---|---|
| `code/` | Canonical processing, analysis, mapping, tables, and reporting code |
| `code/excel_property_level/` | Property-level CSV and Excel formula export |
| `doc/` | Forest Code method references |
| `scientific_presentation/` | Source and assets used to build the presentation |

Data, generated outputs, QA artifacts, and delivery files are excluded from this repository.
